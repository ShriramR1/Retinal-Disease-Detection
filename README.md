# 🩺 Retinal Disease Detection Using Deep Learning

A deep-learning project that classifies retinal OCT images into **four categories** using CNN and transfer learning.

* **Classification** – predict CNV, DME, DRUSEN, or NORMAL.
* **Model Comparison** – compare five deep-learning models.
* **Grad-CAM** – visualize important regions influencing predictions.
* **Dashboard** – Streamlit application for image upload and disease prediction.

## Files

| File | Purpose |
|---|---|
| `Retinal_Disease_Detection.ipynb` | Data preprocessing, model training, evaluation and Grad-CAM |
| `app.py` | Streamlit prediction dashboard |
| `requirements.txt` | Required Python libraries |
| `best_model.pt` | Trained model checkpoint generated by the notebook |


Keep all files in the same folder.

## Quick Start

**1. Install libraries**

```bash
pip install -r requirements.txt
```

**2. Run the notebook**

Open `Retinal_Disease_Detection.ipynb` in Jupyter Notebook or Google Colab and run all cells.

For faster training, select **T4 GPU** in Google Colab.

**3. Run the dashboard**

```bash
streamlit run app.py
```

Open <http://localhost:8501> in your browser.

## What the Notebook Does

| Step | Description |
|---|---|
| 1 | Load the OCT dataset from Hugging Face |
| 2 | Preprocess and augment images |
| 3 | Select 4,000 balanced training images across four classes |
| 4 | Build and train a Custom CNN |
| 5 | Apply transfer learning using ResNet18, DenseNet121, VGG16 and MobileNetV2 |
| 6 | Evaluate models using accuracy, precision, recall and F1-score |
| 7 | Generate Grad-CAM visualizations |
| 8 | Save the best model as `best_model.pt` |

## Results

**Model Performance on the Test Dataset**

| Model | Accuracy | Precision | Recall | F1-score |
|---|---:|---:|---:|---:|
| ResNet18 | **97.50%** | 97.51% | 97.50% | 97.49% |
| DenseNet121 | 97.40% | **97.54%** | 97.40% | 97.38% |
| VGG16 | 96.10% | 96.36% | 96.10% | 96.11% |
| MobileNetV2 | 94.10% | 94.57% | 94.10% | 94.03% |
| Custom CNN | 66.70% | 74.02% | 66.70% | 63.00% |

**Best Model:** ResNet18 with **97.5% accuracy**.

## Dashboard Features

* Upload OCT images in JPG, JPEG or PNG format.
* Predict CNV, DME, DRUSEN or NORMAL.
* Display prediction confidence and class probabilities.
* Visualize important image regions using Grad-CAM.

## Troubleshooting

* **`best_model.pt not found`** – run the notebook first to generate the model.
* **PyTorch import error** – install the required PyTorch and torchvision libraries.
* **Slow training** – use Google Colab with a T4 GPU.

## Limitations

* Training uses a balanced subset of 4,000 images instead of the complete training dataset.
* Patient-level separation cannot be guaranteed because patient IDs are unavailable in the workflow.
* This project is an educational prototype and is **not a substitute for professional medical diagnosis**.
